## 2026-10-07: State the wallet model and the need in pitch material

Marcus corrected the problem slides twice in one session.

- He said an agent pays from its own agent wallet, not from the owner's personal wallet.
- He said the real problem is why agents need privacy, not that payments are public.

Rules for next time:

1. Name the wallet each time. Use "agent wallet", "funding wallet", and "owner". Never write "your wallet".
2. State the need before the exposure. "Payments are public" is a fact. The problem is what the agent's owner loses.
3. When a slide claims a leak, say which link leaks: payment to payment (the agent's activity), or agent wallet to owner (the funding transfer).
4. Open every cited source and check that it supports the exact claim on the slide.

Rule 4 is my own addition. It comes from the 75.41 million figure, which its cited paper only quoted.
